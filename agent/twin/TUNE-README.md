# Layout tuner: resize Ody by hand

Only you see it. It loads when the address ends in `?tune=1` or when you press **Ctrl+Alt+T**. Judges never get it.

1. **Open it.** Go to `http://localhost:8790/?tune=1` (or press **Ctrl+Alt+T** on the app). A panel appears on the right. Drag its title bar to move it, use **⇆** to dock it on the other side, and **–** to fold it away.
2. **Change sizes everywhere.** Open a group (Space, Text, Radius, Motif…) and drag a slider, or type a number. The page updates as you go. **↺** puts one value back.
3. **Move and resize things directly.** Click **Move & resize** (or press Ctrl+Alt+E). Point at something and click it to pick it. Drag it to move it, drag the small squares to resize it (hold Shift on a corner to keep its shape), and hold **Alt + scroll** to make it bigger or smaller. Arrow keys nudge it (Shift moves 10px). **P** picks the box around it, **D** picks the layer underneath, and **Esc** lets go.
4. **One page or all pages.** "Apply to" is set to **All pages** to start with. Switch it to **this page only** to change just Argo, Home or The Forge.
5. **Check and undo.** Hold **Compare** to see the original design. Use **Ctrl+Z** to undo and **Ctrl+Y** to redo. **Reset all** clears everything.
6. **Keep it.** Your changes save in this browser by themselves. Click **Export** to download `ody-layout.json`, then send that file (or click **Copy CSS** and paste the result) to whoever is building the app, so it can go into the real design. **Import** loads a saved file back in.
